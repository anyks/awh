# Сличение кодека XML со сторонними реализациями

Отчёт переехал к набору замеров кодека —
[benchmark/codec/xml/COMPARISON.md](../../../benchmark/codec/xml/COMPARISON.md).
Туда же сведены оба снятия — 18.08.2026 и 24.08.2026, — прежде лежавшие порознь и
разошедшиеся числами.

Здесь, в `tools/benchmark/xml`, лежат сами стенды сличения: по файлу на соперника,
`build.sh` для сборки и [README.md](README.md) с порядком запуска. Отчёт же держится
рядом с набором замеров кодека, вместе с собственными его показателями, — так заведено
у всех кодеков, и раздваивать запись сличения нельзя: разошедшиеся числа в двух файлах
одного смысла не позволяют понять, какому верить.
