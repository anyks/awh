# Стенды сравнения модуля регулярных выражений

Стенды меряют скорость сопоставления модуля `awh::regex` и эталонной реализации
PCRE2 на одном и том же наборе выражений и текстов.

## Условия сравнения

Выражения, тексты и количества повторений вынесены в `scenarios.hpp`, границы
прогрева и замера — в `driver.hpp`. Оба стенда пользуются ими как есть: стенд,
заводящий их у себя, рано или поздно разойдётся с соседним, и сравнение начнёт
мерить разницу образцов, а не реализаций.

Эталон собирается **с компиляцией выражения в машинный код**: сравнивать
реализацию с соперником, работающим не в полную силу, бессмысленно. Стенд эталона
выводит признак её применения. Исходные тексты компилятора получаются подмодулем
внутри подмодуля:

```
git -C submodules/pcre2 submodule update --init deps/sljit
```

Без них сборка проходит, но эталон работает истолкованием, о чём стенд
предупреждает.

Сборка выражения замером не охватывается: она выполняется однажды, тогда как
сопоставление — на каждом обмене, и смешение их показало бы скорость сборки,
а не скорость сопоставления.

## Сборка и запуск

```
./tools/benchmark/regex/build.sh [каталог сборки] [каталог эталона]
/tmp/rival-regex/awh
/tmp/rival-regex/pcre2
```

Оба стенда принимают фильтр названий сценариев первым доводом и признак
`--digest` для вывода накопленных итогов.

## Состав сценариев

Набор покрывает способы исполнения выражения по отдельности:

| Группа | Что меряется |
|---|---|
| `literal-*` | Отбор позиций сопоставления по обязательному литералу |
| `digits-*`, `word-*`, `dotstar-*` | Классы символов и кванторы повторения |
| `alternate-*` | Выбор одной из ветвей |
| `anchored-*`, `boundary-*` | Привязки к позиции в тексте |
| `captures-*` | Установка границ захваченных групп |
| `request-*`, `address-*` | Разбор, встречающийся при работе с протоколами |
| `*-heavy` | Исполнение с возвратом: ссылки, проверки окружения, рекурсия |

Сценарии на коротком тексте меряют накладные расходы одного сопоставления,
на длинном — скорость прохода текста. Сценарий `literal-absent` отделён
намеренно: проход текста целиком стоит иного, нежели прекращение на первом
совпадении.
