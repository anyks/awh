# Сличение разбора YAML с эталоном

Стенд сличает разбор текстов модулем `awh::codec::yaml` с набором **yaml-test-suite** —
общепризнанным собранием из 351 описания случаев, где для всякого дан ожидаемый **поток
событий** в записи вида `+STR / +DOC / +MAP / =VAL :имя`, а для негодных текстов — указание
`fail: true`.

Сличение это закрывает то, чего не закрывают ни набор проверок, ни ворошитель:
**соответствие стандарту**. Ворошитель сличает нас с нами же — он ловит расхождения между
способами подачи и порчу памяти, но если мы неверно понимаем стандарт, он ошибётся вместе
с нами. Набор же проверок написан теми же руками, что и кодек, и разделяет с ним всякое
заблуждение.

## Запуск

```sh
tools/verify/codec/yaml/build.sh /tmp/verify-yaml   # сборка стенда и получение корпуса
python3 tools/verify/codec/yaml/compare.py /tmp/verify-yaml
```

Расхождения раскладываются в `diffs.json` того же каталога: для всякого случая там
эталонный поток событий и наш.

## Устройство

`events.cpp` — щуп: читает текст потоковым чтением и выдаёт поток событий записью набора.
`compare.py` — разбирает описания случаев, прогоняет щуп и сличает выдачу.

Знаки набора: `␣` — пробел, последовательность `———»` — одна горизонтальная подача, `∎` —
конец текста без перевода строки.

## Итог прогона 18.08.2026

Всего 406 случаев (описания несут по несколько написаний каждое).

| исход | количество |
|---|---|
| поток событий совпал | 164 |
| негодный текст верно отвергнут | 67 |
| **негодный текст принят** | **38** |
| **годный текст отвергнут** | **108** |
| поток событий разошёлся | 29 |

Отвергнутое разложено по причинам отказа:

| причина | случаев | что за нею стоит |
|---|---|---|
| знак недопустим в этом месте | 41 | сложные ключи `? `; простые значения, открытые знаками `?`, `:`, `-` без пробела за ними; знак `#` без пробела перед ним |
| скалярное значение не закрыто оградой | 35 | **многострочные значения в ограде** — отложены при заведении чтения намеренно, помечено в исходном тексте |
| знаки за окончанием документа | 11 | содержимое за чертой `...` в том же потоке |
| прочее | 21 | подача в отступе, метки типа, поточные построения, директивы |

**Работы эти к заведению модуля не относятся** — это незаведённые части стандарта, и
перечень их здесь ведётся открыто, дабы не выдавать половину дела за целое.
