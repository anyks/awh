# Сличение разбора YAML с эталоном

Стенд сличает разбор текстов модулем `awh::codec::yaml` с набором **yaml-test-suite** —
общепризнанным собранием из 351 описания случаев, где для всякого дан ожидаемый **поток
событий** в записи вида `+STR / +DOC / +MAP / =VAL :имя`, а для негодных текстов — указание
`fail: true`.

Сличение это закрывает то, чего не закрывают ни набор проверок, ни ворошитель:
**соответствие стандарту**. Ворошитель сличает нас с нами же — он ловит расхождения между
способами подачи и порчу памяти, но если мы неверно понимаем стандарт, он ошибётся вместе
с нами. Набор же проверок написан теми же руками, что и кодек, и разделяет с ним всякое
заблуждение.

## Запуск

```sh
tools/verify/codec/yaml/build.sh /tmp/verify-yaml   # сборка стенда и получение корпуса
python3 tools/verify/codec/yaml/compare.py /tmp/verify-yaml
```

Расхождения раскладываются в `diffs.json` того же каталога: для всякого случая там
эталонный поток событий и наш.

## Устройство

`events.cpp` — щуп: читает текст потоковым чтением и выдаёт поток событий записью набора.
`compare.py` — разбирает описания случаев, прогоняет щуп и сличает выдачу.

Знаки набора: `␣` — пробел, последовательность `———»` — одна горизонтальная подача, `∎` —
конец текста без перевода строки.

## Случаи без эталонного потока

Девять случаев из четырёх описаний — `96NN`, `JEF9`, `MUS6`, `ZYU8` — несут текст,
но эталонного потока событий не несут вовсе: набор говорит о них, что они годны по
правилам описания, однако полезными не являются, и составители поддержку их поощрять
не желают. Сличать там нечего.

Пропускались они прежде совсем, и падение разбора на них осталось бы незамеченным.
Ныне щуп на них выполняется, и прекращение его работы сигналом либо донесением
санитайзера отчитывается отказом.

Отдельно считаются случаи, где набор оставил в теле указатели знаков `<SPC>` и
`<TAB>` пояснением для человека: подставить их нечем, и сличению они не подлежат.
Прежде такой случай отбрасывался молча, ни в один счётчик не попадая, — отчёт
выглядел полным, не будучи им.

## Итог прогона 19.08.2026

Всего 406 случаев (описания несут по несколько написаний каждое).

| исход | количество |
|---|---|
| поток событий совпал | 303 |
| негодный текст верно отвергнут | 94 |
| **негодный текст принят** | **0** |
| **поток событий разошёлся** | **0** |
| эталона в описании нет | 9 |

Девять случаев без эталона — это описания, где набор потока событий не даёт вовсе:
сличать там нечего, и в счёт совпавших они не идут.

Расхождений не осталось. Итог этот держится строгостью: `негодный текст принят` обязан
оставаться нулём при всяком росте совпавших, и всякая правка сличается по обоим числам
разом — иначе рост покупается ослаблением отказов.

**Догадки щупа.** Набор сверки метит поточное построение скобками, а признак этот чтение
выдаёт детям построения, а не самому ему: щуп доискивается скобки розыском по исходному
тексту от места события. Розыск этот есть догадка, и расхождение по ней есть изъян щупа,
а не кодека — проверять её надлежит первым делом. Так были сняты три мнимых расхождения
(`compare.py` не читал явного указателя отступа `|2`) и одно (`82AN` — проверка черты
`---` без пробельного знака за нею).
