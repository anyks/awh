# Сличение разбора TOML с эталоном

Стенд сличает разбор текстов модулем `awh::codec::toml` с набором **toml-test** —
общепризнанным собранием, где для всякого годного текста дано ожидаемое дерево записью
JSON, а негодный обязан быть отвергнут. Скалярное значение эталон записывает парою вида
`{"type": "integer", "value": "42"}`.

Сличение это закрывает то, чего не закрывают ни набор проверок, ни ворошитель:
**соответствие описанию**. Ворошитель сличает нас с нами же — он ловит расхождения между
способами подачи и порчу памяти, но если мы неверно понимаем описание, он ошибётся вместе
с нами. Набор же проверок написан теми же руками, что и кодек, и разделяет с ним всякое
заблуждение.

## Запуск

```sh
tools/verify/codec/toml/build.sh /tmp/verify-toml   # сборка стенда и получение корпуса
python3 tools/verify/codec/toml/compare.py /tmp/verify-toml/corpus /tmp/verify-toml/dump
```

Расхождения раскладываются в `diffs.json` каталога корпуса: для всякого случая там
названо, что именно разошлось и по какому пути.

## Устройство

`dump.cpp` — щуп: читает файл настроек и выдаёт дерево записью JSON договора набора.
Годный текст выдаётся с кодом 0, негодный — с кодом 1.
`compare.py` — прогоняет щуп по корпусу и сличает выдачу с эталоном.

**Версия описания.** Кодек ведёт разбор по TOML 1.0.0 — так сказано в заголовке модуля, —
а набор несёт случаи двух описаний разом. Отбор ведётся перечнем `files-toml-1.0.0` из
самого набора: без него кодеку вменялось бы в отказ то, чего он не обещал.

## Итог прогона 23.08.2026

| исход | количество |
|---|---|
| дерево совпало | 210 |
| негодный текст верно отвергнут | 493 |
| негодный текст принят | 1 |
| дерево разошлось | 0 |
| годный текст отвергнут | 0 |
| отсеяно как случаи 1.1.0 | 68 |

**Что нашло сличение.** Снятие владеющего значения с дерева теряло ВСЁ поддерево там, где
таблица заведена составным именем: заголовок `[a.b]` объявляет одну лишь `a.b`, а звено
`a` заводится им неявно и записи объявления не имеет. Опора снятия на запись объявления
такое звено пропускала молча. Тем же корнем набор таблиц снимался одною первою таблицею, а
перечень дочерних имён не раскрывал звено составного имени внутри таблицы встроенной.
Перезапись дерева при этом оставалась верной, оттого ни ворошитель, ни проверки расхождения
не видели: оно живёт в снятии, а не в дереве. Закреплено проверками
`CodecTomlValue.AbsorbsImplicitTables`, `CodecTomlValue.AbsorbsArrayOfTables` и
`CodecTomlDocument.KeysOfImplicitLink`.

**Второе, что нашло сличение.** Адресация вложенного набора таблиц была несогласована
сама с собою: чтение отвечало по `a`, `0`, `x` и по `a`, `b`, `0`, `y`, но не по
`a`, `0`, `b`, `0`, `y`. Корень тот же — ключ указателя строился по одному имени, без
номера объемлющей таблицы, и объявления `[[a.b]]` из разных элементов набора `a`
сливались в один набор, теряя принадлежность родителю. Описание же относит такое
объявление к ПОСЛЕДНЕЙ таблице набора.

Ключ теперь строится на ключе объемлющей таблицы, а сама она разыскивается по
объявленным, а не сличением с нынешней: между двумя `[[a.b]]` встаёт объявление глубже
вложенное, как `[a.b.c]`, и сличения с нынешней таблицей не хватило бы. Закреплено
проверками `CodecTomlDocument.NestedArraysBelongToElement`,
`CodecTomlDocument.NestedArrayAccumulates` и `CodecTomlValue.AbsorbsNestedArrays`.

**Остаток.** Один принятый негодный текст: текст в кодировке UTF-16 при описании,
дозволяющем один лишь UTF-8 (`utf16-bom`). Приведение кодировок признаёт UTF-8 и обе
разновидности UTF-16, а UTF-32 отвергает прямо, кодом `UNSUPPORTED_ENCODING`, — широта
эта осознанная, и расхождение с эталоном идёт от неё, а не от оплошности. Вопрос о том,
отвергать ли метку не-UTF-8 по умолчанию, вынесен владельцу 29.08.2026.

Прежде остаток числился шестью текстами: четыре о дозаписи составным именем в таблицу,
уже определённую (`append-with-dotted-keys`), и один о доливе к набору, объявленному
ранее (`extend-defined-aot`). Пять этих закрыты; замер 29.08.2026 даёт 711 случаев -
дерево совпало 210, негодный текст отвергнут 500, годный текст отвергнут 0, дерево
разошлось 0.

**Строгость.** Числа `негодный текст принят` и `дерево разошлось` обязаны падать, а не
расти, и всякая правка сличается по обоим разом: рост совпавших, купленный ослаблением
отказов, ростом не является. Сличитель отвечает отказом при всяком расхождении.

**Догадки сличителя.** Нечисло сличается признаком, а не равенством: `nan` не равно ничему,
включая себя. Отметка времени сличается по составу, а не по записи: набор приводит долю
секунды к трём знакам, тогда как описание число знаков сохраняет за человеком, и `.6`
с `.600` дают одно время. Дробные числа сличаются числом: запись их у разных средств
расходится в последних знаках. Расхождение по любой из этих догадок есть изъян сличителя,
а не кодека, и проверять её надлежит первым делом.
