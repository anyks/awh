# Наречие kqueue (macOS, FreeBSD, NetBSD, OpenBSD, DragonFly)

## Как проверяется разбор отвергнутых подписок

Ядро может отвергнуть подписку, и разбор такого отказа разводит три случая: временный
отказ подаётся заново следующим оборотом, окончательный доносится потребителю откликом
`EVENT_FAIL` с текстом причины и сносит узел, неизвестный — повторяется с пределом.

**Из открытого договора этот путь не достижим:** негодную подписку движок не подаёт,
а потребитель подать её не может. Оттого проверка ставится **разовым отладочным ходом**,
который вписывается на время отладки и снимается после. Метода ради одной лишь проверки
в API не заводится: он не нёс бы потребителю никакой пользы.

### Способ (проверен 30.08.2026, macOS)

В `poll()`, непосредственно перед подачей пачки изменений ядру (там, где проверяется
`::local::change.empty()`), временно вписывается порча первой записи:

```cpp
if((::getenv("AWH_DEBUG_BAD_SUBSCRIPTION") != nullptr) && !::local::change.empty())
    // Заведомо негодный дескриптор: ядро ответит EBADF
    ::local::change.front().ident = 999999;
```

Щуп (`tools/fuzz/blockprobe.cpp`) заводит узел, подписывается на отклик об ошибке и
делает обороты опроса. Ожидаемый исход:

```
Event change rejected: ident=999999, filter=-1, Bad file descriptor (node: id=1, ...)
ПОТРЕБИТЕЛЬ ПОЛУЧИЛ ОТКЛИК: узел 1, код 4, причина: Bad file descriptor
```

### Три ловушки, стоившие времени

**Портить нужно ДЕСКРИПТОР, а не фильтр.** Разбор ограничен подписками чтения и записи
(`item.filter == EVFILT_READ || item.filter == EVFILT_WRITE`), и отказ по иному фильтру
до классификации не доходит вовсе. Оттого `EVFILT_VNODE` на сокете, хотя и отвергается
ядром с `EINVAL` на всех четырёх системах, для проверки разбора **не годится**.

**Ход надо ставить в рабочий путь.** `::local::commit()` зовётся только при включённом
`DEBUG_MODE`; ход, вписанный в неё, рабочую сборку не задевает.

**Журнал щупа не глушить.** Заглушённый журнал прячет и причину отказа, и собственные
сообщения движка — за одну сессию это трижды оставляло опыт без объяснения.
