# Сводка сличения девяти кодеков — итоговое состояние зоны

Сведено 13.11.2026. Этот документ — единая точка входа: итоговое место каждого
кодека среди соперников, принятые правки, отвергнутые кандидаты и закрытые
договорные решения. Подробный датированный журнал остался в отдельных отчётах
`<кодек>/COMPARISON.md`; здесь он не переписывается, а сводится к итогу.

Все девять отчётов **парны по версиям**: ряды пересняты одним окном 08–11.11.2026,
указатели подмодулей-соперников зафиксированы `git describe` в момент съёма.
Прежние оговорки о непарности сняты по факту пересъёма. Мера окна берётся по
сторонам, чьи указатели не сдвинуты, и раздельно по осям чтение/запись.

## Итог зоны: плато, цель достигнута

Обязательная цель — обогнать `libxml2` в XML — **достигнута**; прочим кодекам
«не последнее место» — выполнено. Дешёвые местные кандидаты исчерпаны: остаток
разрывов лежит в устройстве соперников (арена rapidyaml, «Perf overhaul» toml++,
единица значения nlohmann/rapidjson), а не в наших ходах. Свежий профиль на тихом
образе (Fedora .167, 13.11) подтвердил: в дереве TOML ходов с призом ≥5 % нет
(кандидат «предварить хэш-таблицы имён» отвергнут мерой, `perf-1112/ROUND.md`).
Дальнейшие правки ниже порога приёмки ≥5 %.

## Принятые правки (действуют в дереве)

* **XML**: снятие владеющего дерева (+24.9 %), слияние двух проходов по строке,
  ленивое место атрибута, быстрое точное закрытие, имена смещениями; разрыв с
  `libxml2` закрыт (device +14.3 %, attributes +1.3 %).
* **YAML**: слитный перенос печатных US-ASCII и перечни написаний ведомой длины
  (дерево +12…+72 %, поток +16…+87 %); быстрый пропуск октетов в приведении
  (дерево +50 % на блоках, поток +67 %); розыск повторов имён сортировкой;
  **№82 — ссылка именем пары раскрывается скаляром** (коммит `e82fda3b7`,
  кластер 14/14, сличение с набором 269/0).
* **TOML**: слитный ход тела строки (+28.6 % strings, +7.4 % service); кэш родов
  имени таблицы; пре-резерв хранилища (+8–15 % large/tables, безвреден).
* **INI**: уплотнение указателей дерева (таблица открытой адресации с ключом в
  слоте, `internal/index.inc`; обход ×2.66, сборка ×1.81, кластер 15/15).
* **CEF/Syslog**: слитный перенос отрезка без обратной косой в `Reader::unescape`
  (CEF поток ×1.385/×1.348, syslog ×1.160/×1.195).
* **ABC**: стража `frame.marked && canonical` в `Writer::account` (+7.0 % objects/write).
* **Общее**: `reset()` у восьми текстовых кодеков; общий `codec::kind_t` в
  `codec/value.hpp`; `abc::kind_t` свёрнут в алиас.

## Отвергнутые кандидаты (мерой, не догадкой)

* **JSON numbers**: архитектурная правка события (`int64/uint64/double` в `event_t`)
  закрыла бы шестую часть разрыва (потолок абляции 1.224 при разрыве 3.1×) — не
  делать как способ догнать; причина в единице значения.
* **TOML**: префиксное дерево (0.80…1.00); предварение хэш-таблиц имён (13.11,
  парная абляция 0.97/0.995/1.004, rehash исчез но выдача слотов съела выигрыш).
* **YAML**: перенос приёма снятия дерева (0.978…1.025); отвод хранилища по длине
  текста; замена реестра имён хэш-структурой (контейнером потолок не берётся);
  сличение меток документа надставкой.
* **CSV**: слитный перенос однобайтовых знаков уже стоит; настройки чтения ~2 %
  (порог не пройден).
* **ABC**: приём YAML (слитный ASCII в `abc::utf8`) дал лишь +2.5 % — снят.

## Закрытые договорные решения (слово владельца 11.11.2026)

| решение | исход | пакет |
|---|---|---|
| **№82** ссылка именем пары YAML | **исполнено**: раскрывать скаляр, вместилище отказывает | `DECISION-82` в `protocols/awh/codec/yaml/` |
| **№74** переустановка узлов CEF/syslog | **оставить**: налог только в сценарии дерева, риск смены жизненного цикла общего `abc::value_t` выше приза | `protocols/awh/codec/DECISION-74.md` |
| **№91** владение входным текстом YAML | **оставить**: прямую дорогу без копии не заводить, приз 3…6 % не оправдывает риска висячих видов | `protocols/awh/codec/DECISION-91.md` |
| **чтение на месте** INI/JSON/TOML | **оставить** тем же словом: копирование входа остаётся | отчёт INI, раздел о разрыве с `inih` |
| **№303** просадка записи `numbers` ABC | **регрессии нет**: тождество 14/14 объектов, проба 0.996 при контроле 0.920 | `protocols/awh/codec/abc-303-2026-11-11/` |

Единая позиция по владению входным текстом: договор не менять ради нескольких
процентов. JSON прямую дорогу уже имеет и платит за неё договором; YAML и INI её
не имеют, и заведение её было бы тем же самым выбором — отклонено.
