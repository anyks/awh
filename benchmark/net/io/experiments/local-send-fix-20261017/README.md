# Исправление допуска локального SEND из READ-callback

Проверенный изолированный прототип от 17.10.2026. Это patch к сохранённому
опыту 09.10.2026, не к рабочему IOCP: в рабочем backend локального SEND ещё нет.

`iocp.cpp.patch` отделяет право отправки от активного ожидания READ. Поле
`localOwner` хранит идентификатор явно допущенного узла. Предикат находит живой
узел по идентификатору, сравнивает адрес без разыменования `udata`, проверяет
статус, транспорт, опции, сокет, порт и поток опроса. При forget и смене владельца
идентификатор сбрасывается вместе с допуском.

Два других patch добавляют идентификатор в явный допуск тестов и echo.
`read-callback.cpp` использует оснастку `local-send-probe.cpp` из полного комплекта
доказательств; в штатную сборку benchmark он не включён. Проверяет реальный READ
при `registered=false`, точные 64 байта, отложенный положительный WRITE,
отмену, уничтожение, поколение слота и forget. Мутация с возвращённым старым
условием падает на `read-callback-send-eligible`.

Полный результат и расположение комплекта: раздел «Исправление допуска SEND
из READ-callback, 17.10.2026» в `../../IOCP-PROFILE.md`.
Перед переносом прототипа требуется отдельная интеграция с актуальным деревом
и устранение прежних замечаний оформления в полном замороженном исходнике.
