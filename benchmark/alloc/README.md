# Замеры распределителя памяти

Стенд сличает наш распределитель `awh::alloc` с системным.

## Как гонять

```sh
benchmark/alloc/stand.sh [корень дерева]
```

Библиотека при этом НЕ собирается: стенд берёт исходники модуля напрямую, оттого
годится и на отладочных стендах, где полная сборка занимает десятки минут.

Переменные окружения: `CXX` — собиратель (по умолчанию `c++`), `FLAGS` — добавочные
ключи сборки.

## Устройство

Из одного исходника `stand.cpp` собираются ДВЕ программы: с нашим распределителем и с
системным (`-DAWH_BENCH_SYSTEM`). Разница между ними одна — какой распределитель
обслуживает выдачу; ключи сборки у обеих совпадают дословно, включая
`-fno-builtin-malloc`.

Семь сценариев: блоки одного разряда, блоки изменчивого размера, крупные блоки,
удержание множества блоков с освобождением вразбивку, рост перевыдачей, нагрузка
потоками по числу ядер и освобождение блока ЧУЖИМ потоком. Наружу идёт лучший из пяти
заходов.

Сценарий, не сделавший ни одного действия, печатает `НЕДЕЙСТВИТЕЛЬНО`, а не ноль:
показатель вида «на одно действие» при нуле действий укладывается в любой порог с
верхней границей, и молчащий сценарий выходил бы зелёным.
